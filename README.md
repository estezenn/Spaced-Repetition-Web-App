# Spaced Repetition Web App

A minimalist and modern spaced repetition web application designed to help users manage their study schedule efficiently.

## Features

- Add and manage lessons/topics
- Automatic spaced repetition intervals (1, 3, 7, 16, 35, 70 days)
- Today view (due, overdue, completed tasks)
- Calendar view (weekly & monthly)
- Drag & drop rescheduling
- Progress tracking per lesson
- LocalStorage-based persistence (no backend required)

## Tech Stack

- HTML5
- CSS3 (Custom styling, no framework)
- Vanilla JavaScript

## How It Works

This app uses the **Spaced Repetition** technique:
You review information at increasing intervals to improve long-term memory retention.

## Getting Started

1. Clone the repo:
git clone https://github.com/yourusername/spaced-repetition-app.git

2. Open `index.html` in your browser.
